# Photographer website

A one-page personal site for a wedding and portrait photographer: hero, portfolio grid, about, and contact. Plain HTML and CSS, no build step.

## Run it

Open `index.html` in a browser, or serve the folder:

```
python3 -m http.server 8000
```

## Edit it

- **Photos:** put images in `images/` and replace a `<div class="ph">` in `index.html` with an `<img>`. Keep them 4:5 portrait so the grid stays even.
- **Placeholders to fill in:** the email address (`hello@example.com`), "[Your City]" in the About section, and the surname.
- **Colours and spacing:** the variables at the top of `styles.css`.
